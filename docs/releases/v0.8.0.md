# DuoFlip 0.8.0 Preview

DuoFlip now supports English and Simplified Chinese. It follows your system’s preferred languages by default, with **Language → System / English / 简体中文** in the menu bar popover for instant switching. Your choice is remembered after relaunch.

Settings, status messages, meeting-app names, sensor errors, and accessibility labels are localized. The repository opens with an English README and English demo, with a separate Chinese README and matching Chinese demo.

## Download and install

Download the Apple Silicon DMG, drag DuoFlip.app to Applications, and open it. The ZIP contains the same app and bilingual usage instructions. Verify downloads against the attached SHA256 file if desired.

Requires macOS 15.2+ and an Apple Silicon MacBook with a readable lid-angle sensor. Effect starts off. Click the menu bar icon to enable it; press Esc to stop the effect while DuoFlip stays open.

This is an **ad-hoc signed, unnotarized preview**. Gatekeeper may block it on other Macs. Screen-recording permission is controlled by macOS. Meeting protection reacts to selected apps running, not confirmed screen sharing. Broader device, Spaces, and meeting-sharing validation remains ongoing.
