## 中文

DuoFlip 首个 GitHub 二进制预览版：随 MacBook 屏幕开合，呈现连续模糊、透视和明暗过渡。

### 下载与安装

- `DuoFlip-0.7.0-arm64.dmg`：打开后将 DuoFlip.app 拖入 Applications。
- `DuoFlip-0.7.0-arm64.zip`：解压后将 DuoFlip.app 复制到 Applications。
- `DuoFlip-0.7.0-SHA256.txt`：两种安装包的校验值。

需要 **Apple Silicon MacBook、macOS 15.2+ 和可读取的翻盖角度传感器**。包内提供中英文使用说明，当前应用界面为简体中文。

### 功能

- 常驻菜单栏，左键打开原生设置浮层，可调节效果强度。
- Esc 立即关闭效果，应用继续常驻。
- 系统权限有效时自动选择内置屏幕，也可使用单次系统选屏。
- 可配置飞书/Lark、腾讯会议、Zoom、Teams 运行时提前关闭效果。
- 画面只在本机内存处理，不保存、不上传，不采集音频。

### 预览版限制

**安装包为 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；其他 Mac 可能被 Gatekeeper 阻止打开。** 这不是已公证的正式版。

实机验证主要基于 MacBook Pro M3 Pro。自动采集在授予持续屏幕录制权限后的完整路径、多 Spaces、真实会议共享兼容性和长期功耗仍待进一步验收。会议避让按软件是否运行判断，不表示检测到正在共享，也不覆盖浏览器会议。首次系统录屏授权必须由用户完成；不接管锁屏或保证唤醒第一帧效果。

校验下载：将安装包与校验文件放在同一目录，运行 `shasum -a 256 -c DuoFlip-0.7.0-SHA256.txt`。若只下载其中一种安装包，另一项会提示文件缺失，可只核对已下载文件对应的校验值。

## English

The first downloadable DuoFlip preview on GitHub brings smooth blur, perspective, and brightness transitions to your MacBook desktop as its lid moves.

### Download and install

- `DuoFlip-0.7.0-arm64.dmg`: open and drag DuoFlip.app to Applications.
- `DuoFlip-0.7.0-arm64.zip`: extract and copy DuoFlip.app to Applications.
- `DuoFlip-0.7.0-SHA256.txt`: checksums for both packages.

Requires an **Apple Silicon MacBook, macOS 15.2+, and a readable lid-angle sensor**. Both packages include Chinese and English usage instructions. The app interface is currently in Simplified Chinese.

### Features

- Menu bar app with a native settings popover and adjustable effect strength.
- Esc stops the effect while leaving the app running.
- Automatic built-in display selection with valid system permission, plus a manual screen-picker option.
- Configurable protection that stops the effect while selected meeting apps are running.
- Local, in-memory image processing, without saved captures, uploads, or audio capture.

### Preview limitations

**Packages are ad-hoc signed, without Developer ID signing or Apple notarization. Gatekeeper may block them on other Macs.** This is not a notarized production release.

Physical-device validation primarily uses a MacBook Pro M3 Pro. The complete automatic-capture path after persistent screen-recording permission is granted, multiple Spaces, actual meeting-sharing compatibility, and long-term power consumption need further validation. Meeting protection detects running apps, not active screen sharing, and does not cover browser meetings. Initial system recording permission must be granted by the user. Lock-screen control and seamless first-frame transitions after wake are not guaranteed.

To verify both downloads, put the packages and checksum file in one directory and run `shasum -a 256 -c DuoFlip-0.7.0-SHA256.txt`. If you downloaded only one package, the other entry will report a missing file; check the checksum for the package you downloaded.
